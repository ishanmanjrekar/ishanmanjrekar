# Hi, I'm Ishan.

I have been a game designer for over 16 years, designing systems, economies, and live operations for games that have reached billions of players worldwide.

This corner of GitHub is my personal practice ground. I am not well versed on the coding aspects at all, but in my free time, I use this space to learn new skills, test modern tools—especially AI collaborators—and explore hands-on ways to build things related to games. For me, it is a quick way to cross the gap between a design idea and a playable build without waiting on a full production pipeline.

---

### 🕹️ Prototypes & Experiments

- **[topdown-2d-car-engine](https://github.com/ishanmanjrekar/topdown-2d-car-engine)** — An arcade car handling sandbox built around push-steering mechanics, drift physics, and touch controls for mobile.
- **[portable-web-android-game-skill](https://github.com/ishanmanjrekar/portable-web-android-game-skill)** — A scaffolding skill that compiles native Android APKs locally without opening Android Studio and exports clean builds to Web and Itch.io.
- **[lootbox-go](https://github.com/ishanmanjrekar/lootbox-go)** — An idle clicker that pokes fun at predatory F2P monetization tropes, from rigged pity systems to artificial energy timers.
- **[yet-another-word-game](https://github.com/ishanmanjrekar/yet-another-word-game)** — A grid-based word puzzle game combining real-time definition lookups and stage progression.
- **[post-like-a-celeb](https://github.com/ishanmanjrekar/post-like-a-celeb)** — A satirical statement generator mocking performative celebrity PR apologies.
